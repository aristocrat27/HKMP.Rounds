# HKMP.Rounds

## English

An HKMP addon that adds a round system, PvP mode switching, match settings management, bench management, map switching, and Phantom Mantis Village creation, managed via an in-game UI (`F6` by default).
<img width="1265" height="1002" alt="image" src="https://github.com/user-attachments/assets/1a391e4c-2247-45a4-ae7f-127b9c01ed44" />

### PvP Mode Selection
* **Quick:** no healing; specific charms (Quick Focus, Kingsoul, Spore Shroom, Hiveblood, Lifeblood, Deep Focus, Weaversong) are removed, while all others are granted.
* **Oneshot:** 1 HP mode; standard nail attacks, Cyclone Slash, Thorns of Agony, and Sharp Shadow deal no damage, select charms are banned, and players start with 1 spell cast (gaining the victim's casts on a kill).
* **Long:** healing is enabled with only Spore Shroom disabled.

### Menu Sections
* **Maps:** map switching, Phantom Mantis Village creation/warping, and room transition controls.
* **Host & Controls:** hotkeys (`/rd`, stats, HUD, freeze/unfreeze), readiness display, HKMP.Timer integration, and visual toggles.
* **Match Control:** manual round controls, win targets, starting SOUL, ready player thresholds, auto-start, and arena/shade rules.
* **Benches:** shared respawn bench viewing, locking/unlocking, syncing with host, setting bench location, and player/bench warping.
* **Statistics:** win statistics window and match results reset.

## HKMP.Timer Integration & Settings
* Rounds end via PvP victory, timer expiration, or host control (with chat duration readouts in stopwatch mode).
* Configuration is handled via the `Open Settings` keybind under `Options → Mods → HKMP.Rounds`, utilizing native Hollow Knight respawn markers with optional Benchwarp support.

## Russian

HKMP-аддон, добавляющий систему раундов, переключение режимов PvP, управление настройками матча, скамейками, картами и Фантомными Деревнями богомолов через внутриигровой UI (`F6` по умолчанию).

### Выбор режима PvP
* **Quick** — режим без лечения: ряд амулетов убирается (*Быстрый фокус*, *Душа короля* и др.), остальные выдаются автоматически.
* **Oneshot** — режим с 1 HP: обычные удары гвоздём, *Ураганный удар*, *Колючки страданий* и *Пронизывающая тень* не наносят урон, часть амулетов запрещена, старт с 1 зарядом заклинания с переходом зарядов при убийстве.
* **Long** — лечение разрешено, отключён только *Споровый гриб*.

### Разделы меню
* **Maps** — переключение карт, создание Фантомных Деревень богомолов и настройка перемещений.
* **Host & Controls** — горячие клавиши (`/rd`, статистика, HUD, заморозка), счётчик готовности, интеграция с **HKMP.Timer** и визуальные эффекты.
* **Match Control** — ручной запуск/завершение раундов, цели по победам, стартовая Душа, автостарт и правила арены.
* **Benches** — управление общими скамейками возрождения, блокировка, синхронизация с хостом и телепортация.
* **Statistics** — окно статистики побед и сброс результатов.

## Интеграция с HKMP.Timer и настройки
* Завершение раунда по победе, таймеру или решению хоста (с выводом времени в чат в режиме секундомера).
* Управление параметрами осуществляется через клавишу `Open Settings` в `Настройки → Mods → HKMP.Rounds` с использованием стандартных точек возрождения игры и поддержкой Benchwarp.
